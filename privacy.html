Privacy policy

Effective November 1, 2026. This policy covers the personal-use Curiel Command Center dashboard and this information site.

Google user data accessed

With the owner's permission, the dashboard accesses information about the selected home and devices, including device identifiers, room or camera names, camera capabilities, and selected cameras' live audio/video streams. Dashboard previews are muted. Home information made available by the granted permission may include home name and postal code; these are not published on this website. The camera integration does not request thermostat control, event history, cloud snapshots, or recorded clips.

Purpose and processing

Device information is used to discover and label authorized cameras. Google's OAuth tokens are used to request, renew, and stop live WebRTC sessions. Live video is processed in memory and displayed inside the dashboard. The dashboard does not record or upload that video to a developer-operated server.

Storage and security

The Shield stores OAuth configuration and refresh authorization encrypted with Android Keystore. Access tokens and live-session data are used as needed for Google API calls. Initial setup may use a loopback-only receiver and restricted configuration files on the owner's Mac. The application package and this public repository do not contain the owner's passwords, tokens, or camera identifiers. Authorized deployment testing may save screenshots on the owner's computer; those images are not part of this public website.

Sharing

Google receives authorized API requests and supplies the camera streams. The dashboard does not sell Google user data, use it for advertising, or disclose it to unrelated third parties. Other independently configured dashboard features may contact their providers, such as Open-Meteo for weather.

Retention and deletion

OAuth configuration is retained on the owner's devices to restore access. Live frames are transient and replaced as playback continues. The owner can revoke the connection in Google Account third-party connections or Nest Partner Connections Manager, clear the dashboard's Android app data to remove local authorization, and delete local setup files or test images. Clearing app data also removes dashboard settings.

This website

This static information site has no login, analytics scripts, forms, or application cookies. GitHub Pages hosts the site and may process technical request data under GitHub's privacy statement. Do not post passwords, tokens, camera images, or other private information in public repository issues.

Contact and changes

For questions or deletion assistance, contact the project owner through the project support page. Material changes to this policy will be reflected here with an updated effective date.
